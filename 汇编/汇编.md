# 基础
## 常见指令


| 操作符                           | 功能         | 实例               |
| ----------------------------- | ---------- | ---------------- |
| mov                           | 移动操作数至目的地址 | mov eax, ebx     |
| push                          | 操作数入栈      | push eax         |
| pop                           | 弹出栈        | pop eax          |
| xchg<br>exchange              | 交换两个操作数    | xchg eax, ebx    |
| lea<br>load effective address | 取地址        | lea eax, [ebx+4] |
|                               |            |                  |

FS和GS扩展寄存器(General Purpose Segment)
	在

TEB(Thread Environment Block)：存储与当前线程相关的信息，FS寄存器指向当前线程的TEB
PEB(Process Enviroment Block):存储与进程相关的信息，64位系统中可以通过FS寄存器访问
SEH(Structured Exception Handling):存储线程的异常处理信息，保存在TEB中，FS寄存器可访问
VEH(Vectored Exception Handling)：全局的异常处理机制，虽然不直接以来FS，但处理线程相关异常时，仍然涉及TEB和FS寄存器
