# 新手专用 · 网络安全实战路线（0 → 能打靶机）

## 总目标（给你一个清晰终点）

**30 天内你要做到：**

- 能独立搭建攻防环境
    
- 能打下 DVWA 的低难度漏洞
    
- 能说清楚：漏洞怎么来、怎么防
    

---

## 第一阶段：环境 + 安全感知（第 1–7 天）

> 目标：**你对网络和系统不再“怕”**

### Day 1–2｜搭环境（非常关键）

必须完成：

- 安装 VMware / VirtualBox
    
- 安装 2 台虚拟机
    
    - Kali Linux
        
    - Ubuntu（或 Windows Server）
        

网络模式：

- NAT（先用这个）
    
- 确保：
    
    ```bash
    ping 通
    ```
    

✔ 判断成功标准  
→ Kali 能 ping 通靶机 IP

---

### Day 3–4｜Linux 生存命令（只学必要的）

你只需要会这些：

```bash
ls cd pwd
ip a
ss -tunlp
ps aux
systemctl status ssh
chmod chown
```

实操任务：

- 开启 SSH
    
- 用 Kali 远程登录靶机
    
- 故意设置弱口令
    

---

### Day 5–7｜第一次“攻击感知”

你要做的不是破坏，而是**理解暴露面**。

```bash
nmap 192.168.XX.XX
```

你要知道：

- 哪些端口开着
    
- 服务是什么
    
- 默认配置有多危险
    

---

## 第二阶段：Web 漏洞实战入门（第 8–20 天）

> 从这里开始，你就“正式入行了”。

### Day 8–10｜搭 DVWA

步骤目标：

- 搭建 LAMP 环境
    
- 成功访问 DVWA
    
- 登录页面能打开
    

不要追求快，**搭成功一次胜过看十个视频**。

---

### Day 11–15｜SQL 注入（第一个核心漏洞）

你要实操的：

- 手工注入（`' or 1=1 --`)
    
- 用 Burp 抓包
    
- 用 SQLmap 验证
    

你必须能回答：

- 为什么拼接 SQL 会出问题？
    
- 预编译怎么防？
    

---

### Day 16–20｜XSS + 文件上传

重点练：

- 反射型 XSS
    
- 存储型 XSS
    
- 图片马上传
    

目标：

- 弹窗不是重点
    
- **理解数据流才是重点**
    

---

## 第三阶段：完整攻击链体验（第 21–30 天）

> 你要第一次“像真的在做安全”。

### Day 21–25｜打一台完整靶机

选择：

- VulnHub 入门靶机
    

流程：

1. Nmap 扫描
    
2. Web 漏洞利用
    
3. 拿 shell
    
4. 提权（sudo / cron）
    

---

### Day 26–30｜复盘（比攻击重要）

你要写一份：

- 攻击路径图
    
- 利用点
    
- 修复方案
    

**安全不是“我能打”，而是“我知道怎么不被打”。**
