# 基础
## 组成
### 计算机
**存储程序**的概念是指将指令以二进制代码的形式实现输入计算机的主存储器，然后按其在存储其中的首地址执行程序的第一条指令，在这之后按照程序规定顺序执行其他指令，直至程序执行结束。

早期计算器可看做输入设备、存储器、运算器、控制器、输出设备组成。
![](组成.png)
在计算机系统中，软件和硬件在逻辑上是等效的。对于乘法运算，既可以设置一个专门的硬件电路实现，也可以通过软件使用多次加法进行模拟。

**现代**计算机以**存储器**为**中心**，CPU=运算器+控制器。主机=CPU+主存。硬件=主机+I/O设备

### 主存储器
由存储体、控制线路、地址寄存器、数据寄存器和地址译码电路等部分组成

存储地址寄存器(Memory Address Register):用于**存储**当前访问的存储单元的**地址**。CPU通过地址线将地址传送给MAR。MAR再将地址信号传递给译码器，以便选择相应的存储单元
存储数据寄存器(Memory Data Register):用于**存储**从存储体中**读取**或**即将写入的数据**。它在CPU和存储体之间传递数据，，确保数据的正确传输。

数据在存储体中按地址存储。
- **存储单元**：每个单元存放一串二进制代码
- **存储字**：存储单元中二进制代码的组合
- **存储字长**：存储单元中二进制代码的位数，常见为32/64
- **存储元**：即存储二进制的电子元件，每个存储元可存1bit

MAR位数反映了存储单元的个数，MDR位数为存储字长
字(word)=16bit , 1B = 8bit

运算器：用于实现算术运算、逻辑运算
ACC(Accumulator)：累加器，用于存放操作数，或运算结果
MQ(Multiple-Quotitent Register)：乘商寄存器，乘除运算时用于存放**操作数或运算结果**(乘积过大时需要用MQ辅助存放)
x：通用的操作数寄存器，用于存放操作数
ALU(Arithmetic and Logic Unit)：算术逻辑单元，通过内部电路实现算术运算、逻辑运算

### 控制器
**CU**(Control Unit)：控制单元，分析指令，给出控制信号
IR(Instruction Register)：指令寄存器,存放当前执行的指令
PC(Program Counter)：程序计数器，存放下一条指令地址，有自动+1的功能。并非固定+1，而是PC+指令长度=下一条指令地址
完成一条指令的过程为取值->分析->执行，实际为PC->IR->CU

1 PC → MAR
2 M[MAR] → MDR
3 MDR → IR
4 PC ← PC + 1
5 IR(地址码) → MAR
6 M[MAR] → MDR
7 MDR → ACC

 ① 取指
PC → MAR  
Memory[MAR] → MDR  
MDR → IR  
PC ← PC + 1
 
 ② 译码
IR(opcode) → 控制单元  
IR(address) 准备操作数地址
 
 ③ 执行
IR(address) → MAR  
Memory[MAR] → MDR  
MDR → ACC / ALU

### 系统软件和应用软件
**应用软件**是为了解决某个应用领域的问题而编制的程序
**系统软件**负责管理硬件资源，并向上层应用程序提供基础服务


### 语言级别
高级语言 → 汇编语言 → 机器语言

高级语言**源程序**通过**编译器**翻译为**汇编语言或中间代码**，再通过**汇编器**转换为**机器语言**（二进制代码）。也可以通过编译器直接翻译为机器语言。

汇编语言是机器指令的**符号化**表示，
其中操作码用**助记符**表示。

**编译程序**：将高级语言源程序一次性翻译成机器语言程序，生成目标程序（如.exe），再执行该程序。

解释程序：**逐条读取**源程序语句，翻译并**立即执行**，不生成独立的目标程序。

编译器、汇编器、解释器统称为**翻译程序**。

很多解释型语言 **并不是直接翻译成机器语言**，而是：
源代码  
↓  
字节码  
↓  
虚拟机执行

### 软件和硬件的逻辑功能等价性
同一个功能既可用硬件实现（性能和成本都高），也可以用软件实现（性能低成本也低）

**指令集体系结构**(**ISA**)：软件和硬件之间的界面。设计计算机系统的ISA，就是定义计算机支持哪些指令，以及每条指令的作用、用法

### 计算机系统层次结构
![](层次结构.png)
下层是上层的**基础**，上层是下层的**扩展**。
计算机体系结构——机器语言程序员所见到的计算机系统的属性概念性的结构与功能特性（指令系统、数据类型、寻址技术、I/O机理）
计算机组成原理——实现计算机体系结构所体现的属性，对程序员“透明”（具体指令的实现）

### 计算机系统工作原理
**源程序**通过预处理器来处理预处理命令，例如宏定义常量的替换
成为**预处理后的源程序**，*通过编译器成为**汇编语言程序***
**汇编语言程序**通过汇编器翻译为**机器语言程序**（目标模块），通过**链接器**再加上*其他被引用的模块*成为**可执行文件**。

### 计算机性能指标
总容量=存储单元个数 x 存储字长 bit
eg:MAR为32位, MDR为8位，则总容量为$2^32*8bit$ = 4GB
**存储器性能指标**：存储容量、存取时间、存储周期、存储器带宽

**CPU性能指标**：主频(时钟频率)、CPI、CPU执行时间(整个程序的耗时)、IPS、FLOPS
CPI：执行一条指令的时钟周期时数
IPS：每秒执行多少条指令$\frac{主频}{平均CPI}$ 
FLOPS：每秒执行多少次浮点运算

**系统性能指标**：数据通路带宽、吞吐量、响应时间
数据通路带宽：数据总线一次能并行传送信息的位数，各硬件部件通过数据总线传输数据
吞吐量：指系统在单位时间内处理请求的数量

基准程序：用来动态测试计算机处理速度的实用程序，以便于可以和其他计算机进行比较

主频高的CPU并不一定更快，还涉及CPI、指令集等，例如乘法和累加乘

基准程序的语句存在频度差，结果不能完全说明问题
